# 🏢 Gestão Condominial - Painel de Pendências Painel web interativo desenvolvido para o acompanhamento e organização de manutenções, melhorias e pendências do condomínio. ## 🚀 Funcionalidades * **Gerenciamento Completo:** Adicionar, editar, excluir e marcar itens como concluídos. * **Barra de Progresso:** Acompanhamento visual em tempo real do andamento das demandas. * **Filtros e Busca:** Encontre rapidamente pendências por status ou palavra-chave. * **Persistência Local:** Dados salvos automaticamente no navegador via `localStorage`. * **Modo Impressão:** Otimizado para gerar relatórios limpos em papel ou PDF. ## 🌐 Publicação no GitHub Pages 1. Crie um repositório público no GitHub. 2. Faça o upload dos arquivos `index.html` e `README.md`. 3. Vá em **Settings** > **Pages**. 4. Na seção *Build and deployment*, escolha a branch `main` (ou `master`) e clique em **Save**. 5. O link do seu site estará disponível instantaneamente!
